# EduPro – Learner Demographics and Course Enrollment Behavior Analysis

## Project Overview

EduPro is an online learning platform that offers courses to learners from different age groups and backgrounds. Understanding learner demographics, enrollment patterns, and course preferences can help the platform make informed decisions about course offerings and learner engagement.

This project focuses on analyzing learner demographics and course enrollment behavior to identify patterns in learner participation, subject preferences, and enrollment trends.

Using Python, Excel, SQL, and Power BI, the project explores learner characteristics and course selection behavior through data analysis and interactive visualizations.

The objective is to transform raw learner and transaction data into meaningful insights that can support data-driven decision-making for the EduPro platform.

## Business Objectives

- Understand the demographic composition of EduPro learners.
- Analyze course enrollment patterns and participation.
- Identify course preferences across different age groups.
- Compare course preferences based on gender.
- Examine learner enrollment behavior and engagement patterns.
- Provide actionable insights to support course planning and platform improvements.

## Key Analytical Areas

- **Demographic Analysis:** Understanding learner distribution across age groups and gender.
- **Enrollment Analysis:** Evaluating course enrollment volume and participation patterns.
- **Age-Based Preferences:** Identifying differences in course interests across age groups.
- **Gender-Based Preferences:** Comparing course selection patterns across gender groups.
- **Behavioral Analysis:** Understanding enrollment frequency and learner participation.


## Conclusion

The EduPro project demonstrates how learner demographic and enrollment data can be transformed into actionable business insights through data analytics and interactive dashboards.

By examining demographic distributions, enrollment patterns, age-based and gender-based course preferences, and learner behavior, the analysis provides a structured understanding of how learners interact with the platform.

The findings can help EduPro make more informed decisions regarding course planning, learner engagement, and the development of relevant learning opportunities.
